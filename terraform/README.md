# ПЗ №12. Автоматичний деплой на EC2

Terraform створює окремий сервер Ubuntu 24.04 у регіоні `eu-north-1` і його групу безпеки. Застосунок з ПЗ №9 запускається в Docker Compose разом із PostgreSQL. GitHub Actions запускає тести, збирає образ і розгортає його через SSH.

## Послідовність перевірки

1. У цій папці виконати `terraform version` і `terraform init`.
2. Задати параметри власного AWS-акаунта в локальному `local.auto.tfvars`. Перевірити `terraform plan -out=pz12.plan` і застосувати план командою `terraform apply pz12.plan`.
3. Налаштувати середовище `ec2-pz12` у GitHub Actions. Адреса EC2 задається через секрет `EC2_HOST`. Ключ SSH, перевірений ключ сервера та пароль PostgreSQL також зберігаються в секретах. Доступ до SSH і порту 3000 відкривається тимчасово для потрібних IP.
4. Увімкнути `ENABLE_PZ12_DEPLOY`, зробити push до `main` і перевірити кроки в Actions. Для перевірки застосунку використати `/healthz` і `/visits` на порту 3000.
5. Після перевірки вимкнути деплой і виконати `terraform destroy`.
