# DevOps ПЗ №9

Застосунок Node.js з PostgreSQL 15. Dockerfile збирає застосунок, а Compose запускає його разом із базою. Іменований том зберігає записи між запусками.

Скопіюйте .env.example у .env, задайте власний пароль PostgreSQL і тег образу, потім виконайте docker compose up --build -d. Стан бази перевіряється через GET /healthz. POST /visits записує відвідування, GET /visits повертає їх кількість.

GitHub Actions збирає образ і формує теги з гілки й коміту. Ручний запуск із publish_image публікує образ у Docker Hub. Опція deploy_ec2 вмикає запуск через Compose на навчальному сервері. Для SSH використовується перевірений ключ хоста і тимчасове правило для IP поточного runner.
